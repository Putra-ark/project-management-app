# TaskFlow — Project Management

A simple Project Management / Task Management app built with React, Vite, and Tailwind CSS.

## Features

- Dashboard with live stats, recent projects, and progress
- Project CRUD (create, edit, delete, detail view)
- Task CRUD with status, priority, and due dates
- Search and filter tasks
- Kanban board with status updates
- LocalStorage persistence

## Tech Stack

- React (JavaScript)
- Vite
- React Router
- Tailwind CSS
- Axios (installed for future API use)
- LocalStorage

## Getting Started

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).
